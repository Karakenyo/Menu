# KARAKENYO Digital Menu

A responsive digital menu built with HTML, CSS, and JavaScript.

## Features

- Mobile-friendly design
- Arabic RTL support
- Elegant restaurant menu layout
- Sticky category navigation
- Fast loading performance
- QR Code ready
- GitHub Pages compatible

## Files

```
index.html
README.md
```

## Deployment

This project can be deployed for free using GitHub Pages.

1. Upload the files to a GitHub repository.
2. Go to Settings → Pages.
3. Select:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
4. Save and wait a few minutes.

Your site will be available at:

```
https://yourusername.github.io/repository-name/
```

## Usage

Open the website link directly or generate a QR code pointing to the website URL.
